## 部署流程

1. 构建 Vue 项目：在 `apps/vue-support-swagger-starter` 下执行 `pnpm deploy`
2. 构建 Spring 项目：`mvn clean install -DskipTests -pl spring-support-swagger-starter -am`
3. 启动 System 服务：`java -jar spring-api-support-system-starter-4.0.0.37.jar`
